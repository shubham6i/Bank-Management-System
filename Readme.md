# Bank Management System

A simple Bank Management System built using **Python, MySQL, HTML, CSS, and JavaScript**.

## Features

- Create a new bank account
- View all accounts
- Deposit money
- Withdraw money
- Check account balance
- Search accounts
- Web-based dashboard
- Command-line interface
- MySQL database for storing account details
- Secure database credentials using `.env`

## Technologies Used

- Python
- MySQL
- HTML
- CSS
- JavaScript
